# 续页 · 学习断片续接器

记录学习中断时的位置、思路和下一步，使用续学卡在电脑、手机和平板上接着学习。

## 第一次启动

需要Python 3.11及以上、Node.js 20.19及以上或22.12及以上（建议使用仍受支持的LTS版本）。

Windows双击根目录的 `start.cmd`。也可以在本目录打开终端：

```powershell
python run.py
```

初次运行需要联网安装依赖和构建界面，之后打开 http://127.0.0.1:8000 。点击“创建账号”，自行设置用户名与密码，没有预设公用账号。启动终端需要保持打开，Ctrl+C停止服务。

重新准备依赖或重新构建：`python run.py --setup`；端口被其他程序占用时：`python run.py --port 8002`。

## 先试这条完整流程

1. 创建账号并登录，点击“新建任务”。填写目标、选择领域插件，可每行输入一个任务步骤。
2. 打开任务，点击“开始学习”。填写“当前做到哪里”“下一步最小行动”，其余内容按需补充。
3. 编辑会在约350毫秒后写入本机草稿；点击“同步草稿”写入服务端。第一版不在每次按键后自动写服务端，便于理解和处理版本冲突。
4. 点击“保存并暂停”，会新增不可覆盖的快照，并结束这一次学习会话。没有AI也能查看模板续学卡。
5. 进入“续学卡与AI”，点击“准备对话上下文”。复制后在连小理中实际对话，再粘贴真实回复。普通文本、JSON或JSON代码块都能导入。
6. 检查AI候选卡，修改后确认。AI原文、候选卡、确认版本和快照分别保留。
7. 下次点击“继续学习”。完成第一个有效行动后可“记录首个有效进展”，时间线会标明由用户确认的耗时。
8. 完成全部任务后“标记任务完成”，或归档。开始前可重新打开已完成的任务。

测试或演示中自行输入的示例不能当作实际应用效果，也不能把HTTP模型回复冒充连小理回复。

## 多设备使用

电脑启动服务后，手机/平板在相同且允许设备互通的网络下打开 `http://电脑局域网IP:8000`，登录同一账号。Windows可运行 `ipconfig` 查找当前网络适配器的IPv4地址。手机的localhost只代表手机自身。

先在原设备“同步草稿”或“保存并暂停”，再到另一设备刷新。若会话仍在原设备运行，新设备可明确点击“接管到本机”。同一账号同时只允许一个活动学习会话。

其他设备旧版本提交会收到冲突提示。点击“刷新状态”对照，然后明确采用服务端版本或保留本机草稿，不会直接覆盖较新记录。断网暂停操作在右上角的“待提交”列表中手动重试；移除操作会保留本机草稿。

跨网络、电脑关机后仍可使用，需要把这套服务部署到有持久化存储的服务器，并配置HTTPS。第一版未发布云端服务。

## 插件与材料

已内置：通用学习、数学推导、编程排障、阅读理解、写作构思。

在 `backend/app/plugins.py` 的 `PLUGINS` 注册一个插件，声明 `name / description / fields / warmup`，前端即可使用统一表单显示新字段。需要新增专门算法时，可在该模块旁添加独立处理器；不要把任意用户输入当成Python或命令执行。

材料从设备上传，单文件最多10MB，通过账号验证后下载。更换设备使用材料ID查找，不依赖某台电脑的磁盘路径。第一版不自动读取其他软件，也不自动解析PDF、运行代码或判断数学证明正确。

## 备份、恢复与离线

在“插件与设置”中导出Markdown、JSON或完整ZIP。ZIP包含当前账号任务、快照、材料与AI交互；恢复生成新任务副本，已有任务不受覆盖。

服务端数据在 `data/study.db` 和 `data/resources/`。不要删除这些目录。数据库运行时优先使用应用导出的ZIP备份，不能只复制一个正在写入的study.db文件。

网页在HTTPS或localhost环境下会注册service worker，缓存界面；每次成功打开工作台也会缓存该任务。之后断网可查看已缓存内容并保存本机草稿。首次未加载的页面或附件仍需联网。普通HTTP局域网可用网页核心功能，但通常不能使用service worker和完整PWA安装体验。

PWA的安装入口因系统与浏览器不同而异。退出登录后不会再自动进入离线空间；本机缓存按账号分开。恢复联网后，打开应用并处理待提交记录。本机缓存不是云备份，清理浏览器数据会清除未同步草稿。

## 可选HTTP AI适配器

复制 `.env.example` 为 `.env`，设置完整的 `AI_API_URL`、`AI_API_KEY`、`AI_MODEL`，重启服务。该适配器发送：

```json
{"model":"你配置的模型","messages":[{"role":"user","content":"本次任务及中断上下文"}]}
```

读取响应中的 `choices[0].message.content`。30秒超时或响应不符合协议时，会记录失败，并保留原始学习信息；可继续使用手动导入。可在 `backend/app/ai.py` 增加其他服务的协议适配器。真实供应商接口需要你提供配置后验证；当前不能保证任意供应商都接受这一协议。

`.env`已被Git忽略，密钥不会发送到前端。部署HTTPS时设置 `COOKIE_SECURE=true`。若使用代理，应保留原始Host；额外可信来源使用 `ALLOWED_ORIGINS=host:port` 配置。

## 开发和检查

```powershell
# 后端测试（临时数据库，不读写你的正式学习记录）
.\.venv\Scripts\python.exe -m pytest -q

# 前端本机存储测试与构建
cd frontend
npm.cmd test
npm.cmd run build
```

需要边改边看时，后端在根目录运行 `.\.venv\Scripts\python.exe -m uvicorn backend.app.main:create_app --factory --reload --port 8000`；另一个终端在frontend中运行 `npm.cmd run dev`，打开它显示的地址。API会由开发服务器代理。

内置接口文档在 http://127.0.0.1:8000/docs ，登录后可测试业务接口。
