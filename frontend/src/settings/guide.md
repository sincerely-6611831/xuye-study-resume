# 续页 · 完整使用手册

这份手册覆盖当前软件的学习记录、AI、语音、数据迁移、个性化与各设备入口。你可以在「个人 → 设置 → 使用教程」阅读，也可以下载本 Markdown 文件离线保存。

## 1. 第一次打开

1. 首次进入会出现简短引导；之后可在「个人 → 设置 → 使用教程」查看完整说明。
2. Windows 安装版在独立程序窗口中运行；Android 手机和平板版打开后有本机学习空间；浏览器网页版的数据保存在当前站点与当前浏览器。
3. 先创建一项任务，再开始学习。无需先配置 AI；普通记录、暂停和续接可以离线使用。
4. 如果是从其他设备换过来，请先到「个人 → 设置 → 数据与同步」导入原设备的完整 ZIP，或连接你自行部署的服务器主动接收任务。

## 2. 总览页

- 总览展示当前任务数量、待续接事项、近期进度和优先打开的任务。
- 点击任务卡可直接进入学习工作台；点击「新建」可以创建任务。
- AI 总结框需要在「模型与 API」中选好可用模型，并由你主动点击生成。发送给模型的是当前任务的有限摘要；结果只作为参考，不会自动改写任务。
- 若模型未配置、无可用网络或本机没有任务，可继续使用其他功能。

## 3. 新建学习任务

1. 点击左侧或底部的「新建学习任务」。
2. 填写标题、课程、目标，并选择领域插件。插件决定中断表单中的专门文本框。
3. 可以把大目标拆成步骤；之后可逐项勾选完成。
4. 保存后进入工作台。任务先留在当前设备；跨设备需自己选择同步或导出 ZIP。

## 4. 学习任务列表、已完成与归档

- 「学习任务」显示未归档的任务，点开卡片继续处理。
- 「已完成与归档」可查看已经完成或主动归档的任务。
- 完成表示阶段目标已经结束；归档用于收起暂时不用的任务。历史断点仍保留。
- 如果任务被另一个页面修改，刷新后对照新的版本，再继续编辑。

## 5. 开始学习与步骤进度

1. 打开任务，点击开始学习。一个任务在一台设备上有当前学习会话。
2. 在工作台查看目标、步骤、材料和之前的断点。勾选已经实际完成的步骤。
3. 需要停止时使用「保存并暂停」，留下当前状态与下一步。切换页面前也可保存草稿。
4. 软件会保留会话、步骤和中断记录；图表只统计这些真实记录。

## 6. 中断时怎样填写

1. 至少写清「当前做到哪里」与「下一步最小行动」。下一步尽量写成能立刻开始的小动作。
2. 可补充材料位置、已完成内容、当时的想法、尝试方法、卡住的问题和原始笔记。
3. 选择中断原因。原因不会由 AI 替你修改。
4. 如果选择了数学、编程等插件，还会看到对应的专门字段；自定义插件也是一样。
5. 点击保存并暂停后，这次记录成为独立断点。再次开始时不会抹掉旧断点。

## 7. 语音转写与 AI 填表

1. 在「个人 → 设置 → 模型与 API」配置语音转写接口，填写完整 HTTP(S) 地址、模型、语言与可选密钥。
2. 选择用于整理语音的文本模型；可与普通续学 AI 共用，也可以单独指定。
3. 中断表单中录音或选取音频，转写后先检查文字是否准确。普通 HTTP 的设备环境可能限制麦克风访问，可改用文件上传。
4. 点击「AI 整理为表单」，查看逐字段建议。你可以修改建议、取消某个字段或选择追加/替换。
5. 只有确认后的文本进入表单；任务状态、中断原因、步骤勾选不由 AI 改动。
6. 转写或总结请求会把音频/文字发给你选用的模型接口，可能产生服务费用；不点击就不会自动发送。

## 8. 续学卡与手动连小理

1. 再次打开任务时先读最近一次中断记录和已确认的续学卡。
2. 即使没有 AI，软件也可以从原记录生成保守的模板提示。
3. 选择手动连小理方式时，先复制「准备对话上下文」，到连小理实际对话，再把真实回复粘贴回来。
4. 检查候选卡中的总结、卡点、下一步和热身问题；确认后成为正式续学卡。AI 原文与候选结果仍留在历史中。
5. AI 内容可能不完整或误解原话，特别是数学推导和材料位置，请以原始断点为准。

## 9. HTTP 模型与本地模型

1. 到「个人 → 设置 → 模型与 API」添加配置：名称、完整 API 地址、模型 ID、超时和必要的密钥。
2. 可以添加多套配置并选择当前默认模型；连接测试会实际发出请求。
3. 本地模型可通过设备上已有的兼容 HTTP 接口接入，例如填写本机可访问的接口地址。软件本身不附带模型权重。
4. 编辑模型时，密钥留空表示保留原值；选择清除密钥才会移除。
5. ZIP 会保存模型名称、地址、模型 ID 和选择，不保存密钥。换设备后请重新填密钥并测试接口；`localhost` 指向新设备自身，可能需要修改地址。

## 10. 材料和附件

- 可以给任务加入学习材料，记录页可引用材料位置。
- 单个附件有大小限制；导入或同步时会检查文件大小与 SHA-256 校验和。
- 在没有服务器时，附件先保存在当前设备的学习空间中；完整 ZIP 会带上文件。
- AI 总结和语音填表不会自动读取所有材料，只使用实际提交给接口的内容。

## 11. 学习分析与图表

1. 点击主菜单「学习分析」。
2. 活动图显示近 14 天或近 30 天每天开始学习与保存中断的次数。
3. 点击图表中的日期，下方显示当天明细；再点明细可打开对应任务。
4. 环形图显示任务当前状态；领域分布按任务使用的插件计数；步骤卡显示当前完成数。
5. 没有记录的日期显示零。软件不会把网页停留时间猜作学习时长。

## 12. 自定义领域插件

1. 到「个人 → 设置 → 领域插件」，查看少量内置方案并创建自己的方案。
2. 写插件名称、用途、续学热身问题，再添加最多 12 个专门文本字段。字段可用于断点和语音 AI 填表。
3. 保存后，新建任务时即可选择。插件只是一组表单配置，不会执行任何脚本。
4. 已被任务使用的插件不能删除，以免旧记录失去字段说明。
5. 完整 ZIP 会带走所有自定义插件。手动服务器同步某项自定义插件任务时，也会附带该插件定义。

## 13. 自建服务器手动同步

1. 先按项目中的 `docs/self-host-server.md` 自行部署续页服务器；跨公网建议使用 HTTPS。
2. 原设备与目标设备打开同一服务器地址，并登录同一账号。
3. 在原设备的「个人 → 设置 → 数据与同步 → 自建服务器」选择任务，点击发送所选。
4. 在目标设备点击获取服务器任务，再选择接收所选。软件不会在后台自动同步。
5. 若目标设备有未发送的新内容，会先保留本机副本；若版本冲突，会提示对照处理。
6. 这种方法同步所选任务、附件、断点、AI 交互与该任务的插件定义。外观、字体、所有插件及模型配置请用完整 ZIP 迁移。

## 14. 完整 ZIP 导出与导入

1. 在原设备进入「个人 → 设置 → 数据与同步 → 完整 ZIP」，点击导出。
2. ZIP 包含本机任务、断点、附件、AI 交互、外观设置、字体文件、自定义插件、模型接口配置及语音配置。
3. 数据多时会生成 `part-1`、`part-2` 等分卷。全部保存，目标设备从 `part-1` 开始逐个导入。
4. 导入会生成任务副本，不覆盖已有任务；插件和字体会合并，同编号不同内容会拒绝导入。
5. ZIP 不含模型或语音 API 密钥。到新设备后重新填写密钥并测试模型。
6. 旧版 ZIP 仍可恢复学习记录，但不包含新版个性化设置。清除应用或浏览器数据之前，请在其他位置保存 ZIP。

## 15. 外观、主题、字号与字体

1. 在「个人 → 设置 → 外观设置」选择浅色、深色、跟随系统、暖纸或深海夜读主题。
2. 选择强调色和布局密度；更改会即时应用到整个程序。
3. 拖动字号滑块，在 100% 到 130% 范围内调整；最小值受限制以保持可读性。
4. 可选系统默认、宋体、楷体或黑体。它们使用当前设备已安装的字体，实际形状可能因系统而不同。
5. 也可上传 WOFF、WOFF2、TTF、OTF 字体文件，单个不超过 5 MB。选中后全局使用，ZIP 会保存文件；请确认你有权使用该字体。

## 16. 个人、账号与数据位置

- 「个人 → 账号信息」可查看当前账号或 Android 本机空间的信息。
- 「个人 → 设置」包含模型与 API、外观、插件、数据与同步、本手册和关于我们。
- 浏览器站点、Windows 独立窗口、Android 本机空间各有自己的本机存储，彼此不会自动合并。
- 登出不会代替 ZIP 备份。当前设备的浏览器或应用数据被清除时，本机未转移的记录可能丢失。

## 17. Windows、Android 手机、平板与手表

- Windows 版使用独立窗口，学习记录保存在程序自己的本机空间；它与系统浏览器里的同站点数据不共享。
- Android 手机版提供本机空间、录音/文件交互，以及系统小组件。小组件显示精简概览，不会展示完整笔记或密钥。
- Android 平板版会利用较宽的屏幕显示更多内容；操作逻辑与手机一致。
- 手表端侧重简短查看和快捷返回任务，圆屏上只放必要信息；完整编辑请在手机、平板、Windows 或网页端进行。
- 若 Android 本机空间连接自建服务器，进入的是服务器账号空间。原本机任务不会自动搬迁，先导出 ZIP 再到服务器空间导入。

## 18. 常见问题

### 没有 AI 能否使用？

可以。创建任务、记录断点、步骤勾选、模板续学卡、图表和 ZIP 备份均不要求模型。

### 换设备后为什么看不到任务？

每台设备有独立本机空间。请选择完整 ZIP 导入，或在同一自建服务器账号下主动发送和接收。

### 为什么恢复后模型提示缺少密钥？

密钥有设备绑定的加密保存方式，ZIP 只保存可迁移的接口配置。请在新设备重新输入。

### 为什么图表里的学习次数与打开页面次数不同？

图表只统计已保存的学习会话和中断断点，不统计单纯打开页面或停留时间。

### 自定义字体在另一设备上没有显示？

如果上传过字体文件，请确认导入 `part-1` 分卷；若选择的是宋体/楷体预设，目标设备需要安装对应字体，否则系统会用替代字体。

### 同步冲突怎么办？

先打开本机保留副本与收到的版本对照，确认哪一份要继续使用。不要在未检查之前删除本机副本。
