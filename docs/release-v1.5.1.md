# 续页 v1.5.1 · 显示修复版

本版包含 [v1.5.0 的全部功能](release-v1.5.0.md)，重点修正 Windows 高分辨率显示和 Android 顶部空白区域。

## 修复内容

1. **Windows 字体清晰度**：原生 WebView2 窗口在创建前启用逐显示器 DPI 感知，并在显示器缩放比例变化时调整窗口尺寸，避免 Windows 对整个窗口进行位图放大。
2. **Android 顶部白条**：移除高度只有 48 物理像素、文字在高密度屏幕上被裁掉的原生按钮行。页面直接占用内容区；自建服务器切换和返回本机空间改由“个人 → 设置 → 数据与同步”操作。
3. **Android 15 系统栏**：为强制延伸到系统栏的页面留出安全区域，用应用深色背景覆盖状态栏背后，避免默认浅色底露出白边。

## 安装文件

| 文件 | 设备 |
| --- | --- |
| `XuYe-Setup-1.5.1.exe` | Windows x64 |
| `XuYe-Phone-Tablet-1.5.1.apk` | Android 8.0+ 手机、平板 |
| `XuYe-WearOS-1.5.1.apk` | Wear OS 手表，需与手机版配对使用 |

两个 Android 正式包继续使用同一团队发布签名，版本号为 1.5.1、versionCode 为 3。手表版仍只显示配对手机传来的精简总览。

## 检查范围

前端 37 项、后端 59 项自动测试通过。Windows 打包程序运行时报告逐显示器 DPI 感知模式 2；Android 模拟器已安装并打开本版手机 APK，首页截图未见旧版顶部白条。还核对了 APK 版本号与签名、内置页面资源及上传文件的 SHA-256。真机显示、手表配对和 Windows 安装后的视觉效果仍需在相应设备上验收。
