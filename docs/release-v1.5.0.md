# 续页 v1.5.0 · 首次多端正式发布

续页帮助用户在学习被打断时记录位置、思路和下一步，回来时依据续学卡继续。此次发布提供 Windows 安装包、Android 手机/平板 APK、Wear OS APK；三端使用同一款续页 Logo。Android 两个正式包使用同一发布签名。

## 功能完善过程

1. **建立可续接的学习流程**：从任务、步骤、学习会话和中断快照开始，实现暂停、恢复、首个有效进展、完成与归档；加入预设领域插件及续学卡。
2. **接入 AI 与设置中心**：支持配置多套文本模型 API、手动导入 AI 回复、确认候选续学卡；增加外观设置和团队信息页面。
3. **减轻中断记录负担**：加入录音/音频上传、语音转写、AI 整理与逐字段确认填入。原始记录和 AI 结果分开保存。
4. **让学习资料优先留在本机**：任务、草稿、附件和 AI 记录保存在设备本地；跨设备迁移收敛为两种主动操作——自建服务器手动同步，或导出完整 ZIP 后在目标设备导入。加入 Ollama、LM Studio 等兼容接口入口。
5. **补齐多端入口**：制作首次引导、总览页、Windows 原生 WebView2 窗口、可离线启动的 Android 手机/平板包、Android 桌面小组件，以及圆屏安全边距的 Wear OS 简化总览。
6. **完善日常使用体验**：重新整理界面层级与动效；总览加入 AI 总结；学习分析根据本机记录绘制图表；领域插件可自由添加；主题、强调色、字号和字体可自选，个性化配置进入完整 ZIP；加入可在应用内逐章阅读的 Markdown 使用手册。
7. **准备正式发布**：统一网页、Windows、手机/平板与手表图标；Windows 打包为单个安装程序；Android 包含界面源码并使用团队签名，版本升至 1.5.0。

## 下载与安装

| 文件 | 设备 | 说明 |
| --- | --- | --- |
| `XuYe-Setup-1.5.0.exe` | Windows x64 | 安装后从桌面或开始菜单打开；安装器在缺少 WebView2 Runtime 时联网安装。 |
| `XuYe-Phone-Tablet-1.5.apk` | Android 8.0+ 手机、平板 | 界面和本机功能均在 APK 内，首次打开不需要电脑。 |
| `XuYe-WearOS-1.5.apk` | Wear OS 手表 | 显示简化总览；需与安装手机版的手机配对并通过 Google Play services Data Layer 传送摘要。 |

手表版显示待续接数量和标题，不在手表上编辑完整任务，也不传输附件或模型密钥。手机和平板会各自保存本机数据。更换设备前请在旧设备导出完整 ZIP，再在新设备导入；从 debug APK 换到正式签名 APK 时，也需要先导出 ZIP。

## 发布检查

- 前端自动测试：37 项通过；后端自动测试：59 项通过。
- Windows：Visual Studio 2022、PyInstaller 与 Inno Setup 编译安装包。
- Android：JDK 17、Android SDK 35 构建手机/平板和 Wear OS 正式签名 APK。
- AI 总结、语音识别需要用户自行配置可用模型或接口；安装包不含模型权重。
- Wear OS 真机配对和小组件仍需在目标设备上进一步验收。
