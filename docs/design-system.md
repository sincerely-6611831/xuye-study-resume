# 续页界面设计约定

续页是本地优先的学习工具。界面要让用户先看见“下一步”，再看统计和设置。视觉语言采用纸张、书签、学习路径：温暖的纸色承载记录，墨绿突出行动，线条显示进度。避免紫色渐变背景、均分三张装饰卡和持续运动的背景。

## 层级

1. 每页只保留一个最重要的行动。总览页的“继续任务”比 AI 总结更靠前；AI 总结必须主动点击才调用模型。
2. 标题、正文、辅助文字至少形成三个清楚的字级；任务名称和下一步不能缩成 10px 的提示字。
3. 使用间距与分隔线组织同类信息。指标可以排成一条统计带，内容区再使用卡片；不要把每一条信息都放进等宽卡片。
4. 示例要标为“示例”，不能让用户误以为它是自己的学习记录。

## 色彩与组件

- 基础色板由 `frontend/src/visual-refresh.css` 定义，用户选择的强调色仍由 `frontend/src/settings/settings.css` 提供。新增组件优先使用 `--surface`、`--text`、`--muted`、`--line`、`--accent-ink`、`--button-bg`，同时检查深色模式。
- 主按钮最小高度 44px；输入框与可点击导航也保持便于手机触摸的高度。焦点用清楚的轮廓显示，不能只靠悬停效果。
- 主卡片圆角约 16px；阴影要轻，悬停时才增加层次。页面中不同性质的信息不必都使用卡片。
- 登录页左侧用一张有具体内容的续学卡解释产品；右侧表单保持直接、安静。

## 动效与设备

动效可以更鲜明，但必须解释真实状态。登录页示例续学卡缓慢浮动；总览统计依次进入，下一步主卡的光轨缓慢旋转；当前任务的进度条只由真实完成步骤计算。章节教程切换时有短暂过渡，数据页的两条迁移路线用大面积选择卡明确区分。组件动效使用 `motion/react`，系统要求减少动态效果时取消持续运动与入场动画；简单的悬停反馈由 CSS 完成。手机采用单列，平板保留有效的双列空间。Windows WebView2、Android WebView 和网页共用样式，不依赖在线字体或图片。

## 参考取舍

参考 [UI-UX-Pro-Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的设计系统思路，并将 [Motion](https://github.com/motiondivision/motion) 作为唯一的动效运行依赖。本项目目前没有 shadcn/UI，因此没有引入 Magic UI；React Bits 的成套特效也不适合当前克制的学习界面；总览没有适合手绘图表的数据，因此没有引入 roughViz。后续新增动画时先检查它是否让学习任务更清楚。
