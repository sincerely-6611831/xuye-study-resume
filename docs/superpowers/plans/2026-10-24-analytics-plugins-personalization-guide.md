# 可视化、插件、个性化与手册实施计划

目标：在现有本机优先的续页应用中，增加可交互的学习图表、自定义字段插件、可迁移的外观与字体，以及应用内完整 Markdown 手册。

## 数据边界

- 图表只读本机任务、断点、会话和步骤；空数据明确显示为空，不推测学习时长。
- 插件仅是声明式文本字段与续学提示，不执行脚本。内置方案不可修改，自定义方案可增删；被任务引用的方案不能删除。
- 每个自定义插件任务的同步包携带其插件定义，目标设备收到后安装定义。服务端校验字段、长度和标识符。
- ZIP 版本升为 3，包含任务与外观、模型配置、语音配置、自定义插件、自定义字体。密钥不导出，目标设备需要重新填写。
- 导入先校验全部数据，再以单个 IndexedDB 事务写入任务和偏好；旧版 ZIP 仍可导入。
- 字体文件限制 5 MB，支持 WOFF、WOFF2、TTF、OTF。字号范围为100%–130%。跨设备通过 ZIP 迁移；系统字体名称依赖目标设备安装情况。
- 不运行编译或打包命令，直到用户授权。

## 实施顺序

1. 写并验证数据层测试：插件定义校验与存储、带插件的同步包、ZIP 个性化往返和旧版兼容。
2. 扩展本机数据层及服务端同步校验，再接插件管理界面。
3. 增加可测试的图表聚合函数与可点击查看明细的分析页。
4. 扩展主题、强调色、字号和字体，接入 ZIP 与恢复后的即时刷新。
5. 用 `guide.md` 替换简略的章节内容，在设置中安全渲染并支持下载。
6. 运行非编译验证：单元测试、格式检查、差异检查；记录尚未编译的限制。
