# UI、双路径数据迁移与完整教程实施计划

## 目标

让总览以真实学习进度呈现更鲜明的视觉节奏；数据与同步界面只引导两条跨设备路径：自建服务器手动同步、完整 ZIP 导出与导入；设置内提供覆盖主要功能的可逐章阅读教程。

## 已有基础与取舍

- 保留 IndexedDB 本机优先、FastAPI `device-sync` 的版本校验及 ZIP 完整备份格式，不引入第三方云服务。
- 自建服务器模式复用现有同源网页和登录账号。Android APK 本机空间与服务器空间隔离；切换空间不会暗中迁移数据，首次迁移用 ZIP。
- 数据页保留存储许可和容量说明，但移除 JSON/Markdown 作为跨设备入口，避免出现第三种“同步方式”。
- 动效以真实任务步骤、进度与操作反馈为素材，避免随机统计；尊重系统减少动态效果。
- 不执行前端生产构建、Windows 安装包或 Android APK 编译，直到用户明确授权。

## 工作项

1. 数据页拆成两种明确方法：服务器连接说明和手动发送/接收；ZIP 完整备份与恢复。Android 本机空间提供打开服务器连接设置的入口，并明确数据空间隔离。
2. 自建服务器部署说明写入独立文档，覆盖访问地址、HTTPS、账号、初次 ZIP 迁移、冲突和备份。更新 Android 连接文案与引导文案。
3. 设置中心增加“使用教程”页，按章节解释登录、总览、任务、断点、插件与材料、语音、续学卡与 AI、状态、两种迁移方式、模型、外观、平台差异和故障排查；章节按钮及上一步/下一步可操作。
4. 总览加入从真实任务步骤生成的进度轨迹、分层入场和更有辨识度的视觉形状；登录示例卡和交互反馈增强，适配手机、深色模式及减少动态效果。
5. 运行无需编译的单元测试与静态格式检查，检查文案中是否还把局域网电脑共享描述为第三种同步路径。更新 README，注明安装包仍是旧版。
