# 语音中断记录与个人页

用户要求：中断记录支持AI总结语音并填充文本框；模型设置增加入口；主菜单新增与任务、归档并列的“个人”，将账号信息和设置收纳其中。延续本地运行、中文注释与模块化结构。

实现选择：浏览器录音或上传音频 → 兼容multipart转写接口得到文本 → 用户可修改文本 → Chat Completions模型提取公用字段和当前插件字段 → 用户预览、选择并填入本机草稿 → 原有同步/暂停保存。录音不永久保存，默认追加已有内容，不让AI改任务状态或勾选完成步骤。普通HTTP局域网不支持麦克风时可上传录音或粘贴手机输入法转写文本。

1. 后端配置与接口。新增voice_settings表、settings_voice.py（转写端点、模型、密钥、语言、超时、整理模型选择），voice.py（任务归属验证、20MB音频限制、转写、结构化提取），复用加密和HTTP文本模型。只返回公开配置。提取结果按插件字段白名单、字符串和长度校验，不写入学习记录。
2. 前端语音模块。voice/VoiceCapture.tsx管理录音生命周期；VoiceAssistant.tsx管理转写、文本编辑、提取预览和填入；fields.mjs负责安全合并、白名单和长度限制，独立测试。录音至多3分钟，切页停止并释放麦克风；异步结果不能覆盖更新后的转写文本。
3. 配置与导航。VoiceSettings.tsx从“模型与API”进入，独立保存识别配置，整理可选已有模型或跟随当前默认。Personal.tsx含账号页与设置入口，账号显示用户名、ID、任务统计、退出登录。桌面和移动主菜单统一为学习任务、已完成与归档、个人。
4. 验证。先写并观察失败测试：设置持久化/隔离/密钥、实际HTTP multipart及模型路由、无模型/无配置/上游失败、插件白名单、无隐式草稿修改，前端合并与迟到请求保护。再实现并运行全量测试、构建；独立审查，独立QA数据库验证个人、设置、语音填充及窄屏。真实麦克风及真实供应商需用户配置后验证，不调用用户真实凭据。

进度：功能已实现，基线c3fbd0b，在现有codex/study-resume-v1分支继续。后端先观察4项缺少接口的失败、前端合并模块缺失失败，再实现为绿；补充上游错误脱敏与模型删除回退验证。独立审查发现配置跳转丢失临时口述，已先在浏览器复现，再改为弹窗内打开模型设置并验证原内容保留。独立QA以合成静音与本机固定响应验证转写、预览、填充、暂停和个人设置；360像素视口检查通过。最终后端31项、前端12项测试、生产构建、编译与空白检查通过；本地服务为1.2.0，验收服务已停止。
