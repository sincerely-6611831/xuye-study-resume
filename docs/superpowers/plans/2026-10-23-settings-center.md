# 设置中心实现计划

用户已授权在第一版基础上增加全局设置，保留中文注释与模块化结构。

1. 模型/API：按账号保存多套Chat Completions兼容配置（名称、完整地址、模型、密钥、超时）；可选默认手动模式或HTTP模型；可测试连接、编辑、移除。服务端环境变量继续作为可选默认来源。密钥在服务器加密保存，读接口只返回是否设置；不进入浏览器缓存和学习备份。HTTP生成使用请求提交时的配置快照。
2. 外观：浅色、深色、跟随系统；鼠尾草绿、蓝、紫强调色；小/标准/大字号；舒适/紧凑布局。即时应用，按账号持久化，首次页面加载先应用本机缓存；应用登录后读取服务器设置。
3. 原数据/插件设置保留为独立页；新增关于我们，使用用户提供的审核状态、团队、队长、成员及学校信息。
4. 先添加接口和外观状态测试并观察失败，再实现。验证账号隔离、密钥不回显/不导出、留空保留原密钥、默认模型实际路由、环境变量回退和配置删除行为。
5. 浏览器验证设置保存、主题切换、API配置表单与关于我们；执行全量测试和生产构建，独立审查后修复问题。仅更新本机运行版本，不发布公网。

实现模块：backend/app/settings.py、model_client.py；frontend/src/settings/{Settings,ModelSettings,AppearanceSettings,DataSettings,AboutSettings,appearance}.tsx/mjs。

实施结果：以上功能已实现；独立审查的两项时序问题已修复。后端26项、前端9项测试通过，生产构建成功。浏览器验证模型选择、密钥不回填、外观持久化、团队信息及360像素窄屏布局。具体证据见`docs/验收记录.md`。
